# 자리톡 맞춤법 검사기 업데이트

이 저장소에는 자리톡 맞춤법 검사기 Mac 도우미의 **자동 업데이트 파일만** 있습니다. 소스 코드는 없습니다.

- `appcast.xml`: 설치된 도우미가 4시간마다 확인하는 업데이트 목록입니다.
- Releases의 `d<배포 번호>`: 각 배포의 업데이트 파일입니다.

모든 파일은 회사 Developer ID 서명과 Apple 공증을 거쳤고, 업데이트 파일은 별도 EdDSA 키로 서명했습니다. 설치된 도우미는 두 서명을 모두 확인한 뒤에만 새 버전을 설치합니다. 이 저장소의 파일을 직접 내려받아 설치하지 마세요. 처음 설치는 담당자가 전달한 설치 파일을 사용합니다.

이 저장소는 배포 명령(`npm run release`)이 관리합니다. 파일을 직접 고치지 마세요.
